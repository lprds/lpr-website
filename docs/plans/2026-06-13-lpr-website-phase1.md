# LPR Website — Phase 1 Implementation Plan

> **For agentic workers:** Use superpowers:subagent-driven-development or superpowers:executing-plans to implement task-by-task. Steps use checkbox (`- [ ]`) syntax.

**Goal:** Rebuild lapiedraroja.com as a fast, multi-page, SEO/AEO-ready Astro site that presents LPR's three service pillars and open-ended industries, deployed on Cloudflare Pages.

**Architecture:** Astro (static output, ~zero JS) + Tailwind v4 (CSS-first `@theme` tokens = the brand-config that makes the template reusable for client sites). Reusable layout + section components; one file per page; SEO/AEO baked into a shared `<SeoHead>` + per-page JSON-LD. Contact form POSTs to an n8n webhook. Cloudflare Web Analytics. Deploy from the `lprds` GitHub repo behind the existing Pages project.

**Tech Stack:** Astro · Tailwind v4 · @astrojs/sitemap · TypeScript (light) · Cloudflare Pages · n8n (form endpoint).

**Source spec:** `docs/2026-06-13-lpr-website-overhaul-design.md`

**Brand tokens:** Fraunces / Space Grotesk / Inter · deep red `#5b0e0e` · red `#7a1a1a` · dark `#3d0808` · bright red `#b31b24` · gold `#d4a843` · cream `#fdf6f0` · ink `#2c2c2c` · border `#e0d6cf`. Emblem: `src/assets/lpr-emblem-red.png` (+ white variant).

**Locked design:** light canvas, bold Space Grotesk headlines, red as accent only, gold keyword underline, three-pillar band under hero, open-ended industries ("Industry-fluent … & more"). Reference mockup: `.superpowers/brainstorm/.../directions-v3.html`.
